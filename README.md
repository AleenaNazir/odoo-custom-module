# Bookstore Module for Odoo 19

A simple custom app for Odoo 19 to track books and manage inventory for a bookstore. This project shows how to build a basic Odoo app using Python, PostgreSQL, and XML views.

## Main Features
- Database Model: Uses a Python model (book.store.book) to save book details like Title, Author, Genre, Price, and Description.
- User Interface: Uses Odoo 19 XML tags (<list> and <form>) to build clean screens for viewing and adding data.
- Security: Uses an ir.model.access.csv file to set rules for who can Read, Write, Create, and Delete books.
- App Configuration: Uses a standard __manifest__.py file to install and register the app in Odoo.

## Tech Stack
- Framework: Odoo 19
- Backend: Python
- Database: PostgreSQL
- UI Design: XML
- Code Editor: PyCharm
